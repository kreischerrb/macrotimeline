# MacroTimeline

App pessoal para anotar o que você comeu no dia e acompanhar as **calorias, proteína, carboidrato e gordura**.

Você escreve o que comeu e o app calcula os macros usando a **Tabela TACO** (NEPA/Unicamp) e os alimentos que você mesmo cadastrar.

> Versão 0.1.0: por enquanto é só o esqueleto do app, com as telas ainda vazias. As funções chegam nas próximas versões.

## Onde ficam os seus dados

**Só no seu celular.** Nada é enviado para a internet nem fica guardado neste repositório. Cada pessoa tem os próprios dados no próprio aparelho.

Por isso, se você apagar os dados do navegador ou trocar de celular, os registros não vão junto. Uma função de backup vai chegar numa próxima versão.

## Como instalar no celular

Abra o endereço do app: **https://kreischerrb.github.io/macrotimeline/**

### Android (Chrome)
1. Abra o endereço no **Chrome**.
2. Toque no menu **⋮** (três pontinhos, no canto de cima).
3. Toque em **Adicionar à tela inicial** (ou **Instalar app**).
4. Confirme. O ícone **Macros** aparece na tela do celular.

### iPhone (Safari)
1. Abra o endereço no **Safari**.
2. Toque no botão **Compartilhar** (o quadrado com a seta para cima).
3. Role e toque em **Adicionar à Tela de Início**.
4. Toque em **Adicionar**. O ícone **Macros** aparece na Tela de Início.

**Importante no iPhone:** use sempre o app pelo ícone da Tela de Início. No Safari comum, o iPhone pode apagar os dados depois de 7 dias sem uso.

## Atualizações

Quando sair uma versão nova, o app mostra **"Nova versão disponível"** no topo. Toque em **Atualizar**. Seus dados continuam salvos.

## Crédito

Dados nutricionais: Tabela TACO – NEPA/Unicamp (Tabela Brasileira de Composição de Alimentos, 4ª edição).
